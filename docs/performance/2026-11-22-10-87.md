## 采样方法

- 使用 PowerShell 按 PID 读取已运行的进程，采样前进程已运行约 3 分 40 秒。
- 用 `Stopwatch` 控制采样间隔，每 5 秒记录一次累计进程 CPU 时间、内存和窗口状态，包含起点与终点。
- `Process.TotalProcessorTime` 包含用户态和内核态时间。整机 CPU 百分比等于累计 CPU 时间增量除以实际经过秒数和 32 个逻辑处理器，再乘以 100。5 秒区间沿用相同口径，第 95 百分位取排序后的第 171 个区间值。
- 私有工作集取自按 PID 过滤的 `Win32_PerfFormattedData_PerfProc_Process.WorkingSetPrivate`，表示进程独占的驻留内存。总工作集取自 `Process.WorkingSet64`，包括共享的驻留页面。私有提交内存取自 `Process.PrivateMemorySize64`。内存值取各采样点统计，1 MiB 等于 1,048,576 字节。
